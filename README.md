# Legacy Fortran

**This course is in pre-alpha development.**
**This course is linked to [Introduction to Modern Fortran](https://github.com/carpentries-incubator/intro-to-modern-fortran) and [Unit Testing in Fortran](https://github.com/carpentries-incubator/fortran-unit-testing/).**

So you've been given some Fortran code! This course covers your first steps with your new codebase and how to refactor legacy Fortran.
No Fortran knowledge is assumed.

This course covers:

- A quick start guide outlining what you can do in the first hour, day, week etc with your new codebase
- How to refractor common legacy code patterns and Fortran 'gotchas' into Modern Fortran

## Contributing

If you have examples of legacy or bad practice in Fortran, coding confessions from when you started working on legacy Fortran, or any other suggestions for getting started with a legacy codebase please open an Issue on this repository.

Examples of refactoring legacy Fortran into Modern Fortran should conform to the standards set out in the [Introduction to Modern Fortran](https://github.com/carpentries-incubator/intro-to-modern-fortran/#contributing) course.
